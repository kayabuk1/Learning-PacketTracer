 Learning-PacketTracer

## 概要
Cisco Packet Tracerを用いた、ネットワーク機器のコンフィグレーションやトラブルシューティングの学習記録です。
ネットワークの基礎となるルーティング（RIPv2など）やDHCP、ACLの設定、物理層・データリンク層のトラブル解決のプロセスをメモとして残しています。

## 学習内容
「若年者ものづくり競技大会 ITネットワークシステム管理」の過去課題から一部を抜粋した演習を中心に学習を進めました。
知識として知っているだけでなく、「ミスなく正確にコマンドを指に覚えさせる」ことを目標とし、**各課題につき7回程度の反復学習**を行いました。

## リポジトリの内容
* ルータの各種コンフィグレーション（DHCPサーバ化、RIPv2による動的ルーティング、VTYへのACL適用など）
* PT道場演習メモ（物理層・データリンク層のトラブルシューティング、CDPを活用した隣接ルータの問題解決など）
* 自身の復習用テキスト・構成図の記録
